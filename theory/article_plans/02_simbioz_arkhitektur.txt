================================================================================
СТАТЬЯ 2
Симбиоз классификаторов: ансамблевая интеграция метода подпространственной
сопряжённости с классическими моделями машинного обучения и свёрточными
нейронными сетями
================================================================================

0. ДАТАСЕТ
--------------------------------------------------------------------------------
HAM10000 / ISIC 2018 Skin Lesion Classification (10 015 дерматоскопических
изображений, 7 классов новообразований кожи; Harvard Dataverse /
challenge.isic-archive.com) — открытый медицинский бенчмарк, стандартный
для статей о сравнении/ансамблировании классификаторов в медицинской
визуализации. Выбран не МРТ-датасет проекта намеренно: семь классов вместо
трёх дают более богатую матрицу ошибок для анализа корреляции между
классификаторами (задача 1 плана), а сам домен (дерматоскопия, текстура
поверхности) достаточно близок к МРТ по типу задачи (классификация
патологии по текстуре снимка), чтобы результат был сопоставим с основным
доменом диссертации.

0.1 СРАВНЕНИЕ С МОДЕЛЯМИ ДРУГИХ СТАТЕЙ
--------------------------------------------------------------------------------
Возможно и добавляется в план: + M1 (критерий ранней остановки роста,
статья 1) переобучается на D2 (HAM10000/ISIC2018) и сравнивается с
собственной моделью статьи (M2 — ансамбль). Перенос без адаптации: M1 не
завязан на модальность/размерность входа, а формат задачи (изображение →
вектор → классификация патологии) идентичен MRI-домену, для которого M1
изначально формулировался. Ожидаемый вывод статьи — не только "работает ли
ансамбль M2", но и "сохраняет ли M1 свой выигрыш по времени/точности на
принципиально другом домене (дерматоскопия вместо МРТ)".

1. АКТУАЛЬНОСТЬ И ПОСТАНОВКА ПРОБЛЕМЫ
--------------------------------------------------------------------------------
Честное сравнение (tuned_comparison, --experiment tuned) показало: метод
сопряжённости, классический ML (LinearSVM/LogReg/RF/kNN поверх PCA) и CNN
имеют РАЗНЫЕ профили ошибок — метод сопряжённости стабильно слаб на классе
meningioma (recall 10-53% в разных конфигурациях), тогда как CNN и
классический ML ошибаются иначе (см. confusion matrix draft_method_
experiment_report.json). Разные профили ошибок — классическая предпосылка
для ансамблирования: если ошибки моделей не полностью коррелированы,
голосование/стекинг может дать точность выше каждой модели по отдельности.
Эта возможность в проекте не исследована — все сравнения проводились как
independent horse race, а не как потенциальные компоненты одного ансамбля.

2. ЦЕЛЬ И ЗАДАЧИ
--------------------------------------------------------------------------------
Цель: проверить, даёт ли ансамблевая интеграция (симбиоз) метода
сопряжённости с классическим ML и CNN точность выше, чем лучшая отдельная
модель, и в каком диапазоне объёма данных этот эффект максимален.

Задачи:
  1. Количественно оценить корреляцию ошибок между тремя подходами
     (пофайловое сравнение предсказаний на одном и том же test-сплите).
  2. Реализовать 2-3 схемы объединения: мягкое голосование по вероятностям/
     R-показателям, стекинг (метамодель поверх выходов трёх классификаторов),
     селективное переключение (использовать сопряжённость только для классов,
     где она сильна).
  3. Повторить честный holdout-протокол (--experiment tuned) для ансамбля и
     сравнить с лучшей одиночной моделью на каждой точке кривой объёма данных.
  4. Проверить, снимает ли ансамбль специфическую слабость метода на
     meningioma.

3. НАУЧНАЯ НОВИЗНА
--------------------------------------------------------------------------------
В литературе по методу сопряжённости (обе версии статьи в theory/) метод
рассматривается как самостоятельный, альтернативный нейросетевому. Ансамблевая
интеграция с явной проверкой некоррелированности ошибок — самостоятельный,
ранее не изучавшийся вопрос: не "метод против CNN", а "метод + CNN вместе".

4. СВЯЗЬ С ПРОЕКТОМ mission_6states (готовая база)
--------------------------------------------------------------------------------
  - Три независимо обученных и честно оценённых модели уже есть:
    subspace (SubspaceConjugacyClassifier), classical_ml (sklearn), CNN
    (models/sequential_classifier.py — паттерн композиции уже есть, хоть и
    для другой задачи: двухэтапная, а не ансамблевая композиция).
  - Единый test-сплит для всех трёх подходов уже используется
    (prepare_centered_split, main.py:644-670) — не нужно решать проблему
    сопоставимости сравнения заново.
  - Конкретные confusion matrix трёх подходов на одинаковых test-объектах:
    artifacts/draft_method_experiment_report.json — оттуда же берётся
    статистика по корреляции ошибок (задача 1) без нового прогона.
  - full_data_evaluation в tuned_comparison_{mri,mnist}_report.json даёт
    точные вероятности/R-показатели каждой модели для стекинга.

5. МЕТОДОЛОГИЯ И ПЛАН ЭКСПЕРИМЕНТА
--------------------------------------------------------------------------------
  Шаг 1. Из уже сохранённых предсказаний (или повторного honest-прогона)
         построить таблицу "объект x модель x предсказание" и посчитать
         долю объектов, которые ошибочно классифицирует РОВНО ОДНА модель
         (потенциал ансамбля) против "все три ошибаются одновременно"
         (потолок ансамбля).
  Шаг 2. Реализовать voting/stacking/switching как отдельный estimator в
         новом модуле (например, models/ensemble.py), совместимый со
         sklearn-интерфейсом проекта.
  Шаг 3. Прогнать data-efficiency sweep (10/20/40/80/160 на класс) для
         ансамбля тем же honest-протоколом, что и три базовые модели.
  Шаг 4. Сравнить итоговую кривую с кривыми трёх отдельных подходов
         (уже есть в tuned_comparison_{mri,mnist}_report.json).

6. СТРУКТУРА СТАТЬИ
--------------------------------------------------------------------------------
  1. Введение: метод сопряжённости и нейросетевые/классические подходы
     как альтернативы, а не компоненты
  2. Анализ корреляции ошибок трёх независимых классификаторов
  3. Схемы ансамблевой интеграции (voting/stacking/switching)
  4. Экспериментальный протокол (honest holdout, кривая объёма данных)
  5. Результаты: точность ансамбля против отдельных моделей по точкам кривой
  6. Обсуждение: где симбиоз работает, где не даёт выигрыша
  7. Заключение

7. ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ / КРИТЕРИИ УСПЕХА
--------------------------------------------------------------------------------
  - Явная оценка доли "взаимно исправляемых" ошибок (потолок потенциального
    выигрыша ансамбля).
  - Хотя бы одна точка кривой объёма данных, где ансамбль статистически
    значимо превосходит лучшую одиночную модель.

8. РИСКИ И ОГРАНИЧЕНИЯ
--------------------------------------------------------------------------------
  - При сильно коррелированных ошибках (например, все три путают
    meningioma по одной и той же причине — низкое качество исходных
    снимков) ансамбль не даст выигрыша — это тоже честный, публикуемый
    отрицательный результат.
  - Ансамбль из трёх моделей дороже по времени инференса, чем одна модель —
    нужно явно обсудить компромисс точность/стоимость.
