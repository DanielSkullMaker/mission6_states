################################################################################
СТАТЬЯ 1
################################################################################

1. НАЗВАНИЕ
   Метод подпространственной сопряжённости для классификации медицинских
   изображений: теоретические основы и воспроизведение результатов

2. АННОТАЦИЯ (черновик, ~150 слов)
   Рассматривается метод подпространственной сопряжённости (метод Фурсова)
   для классификации медицинских изображений на примере задачи
   распознавания трёх типов опухолей головного мозга по МРТ-снимкам
   (glioma, meningioma, pituitary). Метод основан на разбиении признакового
   пространства каждого класса на подпространства (подклассы) и вычислении
   показателя сопряжённости R(x, Y) для отнесения нового объекта к классу с
   максимальным значением показателя. Описана каноническая трёхфазная схема
   алгоритма (формирование центров подклассов, наполнение кластеров,
   классификация) и её программная реализация в виде тестируемой
   Python-библиотеки. Приведено воспроизведение результатов на честном
   независимом разбиении данных (80/20, стратифицированное по классам) —
   получена точность 61% на полном наборе из 600 изображений и 80% на
   уменьшенной обучающей выборке, что значительно превышает случайное
   угадывание (33% для 3 классов) и задаёт базовый уровень (baseline) для
   последующих статей.

3. ВВЕДЕНИЕ (план)
   - Актуальность классификации медицинских изображений методами
     машинного обучения; ограничения глубокого обучения в медицинском
     домене (дефицит размеченных данных, интерпретируемость).
   - Место детерминированных подпространственных методов среди
     альтернатив: классические ML-методы (логистическая регрессия, SVM,
     деревья, kNN) и свёрточные нейронные сети — сравнение отложено до
     Статьи 5, здесь — только позиционирование.
   - Обзор публикации-первоисточника: Korshikov V.I., Fursov V.A.,
     "Pathology Recognition Based on Conjugacy Criteria with Subspaces of
     Reference Images" (theory/VI_Korshikov_VA_Fursov_...docx) и более
     раннего чернового варианта (theory/code/Вариант_2_1.docx).
   - Цель статьи: формализовать канонический алгоритм, описать его
     программную реализацию и воспроизвести заявленную точность на
     независимом наборе данных как отправную точку диссертационного
     исследования.

4. ТЕОРИЯ (план, с точными ссылками на источник в репозитории)
   - Показатель сопряжённости:
       R(x, Y) = (xᵀ Y (YᵀY)⁻¹ Yᵀ x) / (xᵀx) ∈ [0, 1]
     Регуляризация Тихонова матрицы Грама (reg_param) для устойчивости
     обращения — `subspace_conjugacy/core/metrics.py::conjugate_criterion`.
   - Косинусное сходство cos(a,b) = (a·b)/(‖a‖·‖b‖) —
     `core/metrics.py::cosine_similarity_matrix`.
   - Три канонические фазы алгоритма (refactoring_plan.txt, раздел 1):
       Фаза A — поиск центров подклассов (A.1 глобальная пара с минимальным
       косинусным сходством, A.2-A.3 последовательное добавление центров
       через минимум R) — `algorithms/global_pair.py`,
       `algorithms/reference_centers.py`.
       Фаза B — формирование кластеров (B.1 второй вектор пары, B.2
       последовательное наполнение через максимум R) —
       `algorithms/subclass_seed.py`, `algorithms/subclass_growth.py`.
       Фаза C — классификация: argmax R(x, Y_{c,s}) по всем подпространствам
       всех классов — `models/classifier.py::SubspaceConjugacyClassifier`.
   - sklearn-совместимый API классификатора (fit/predict/predict_proba) —
     `models/base.py::BaseSubspaceEstimator`.

5. ОПИСАНИЕ ЭКСПЕРИМЕНТА
   - Датасет: `datasets/{glioma,meningioma,pituitary}_centered/*.png`,
     200 изображений на класс, 256x256, grayscale.
   - Препроцессинг: уже выполнен (`ImagePreprocessor`, resize -> подавление
     фона -> центрирование), векторизация — `features.vectorization`,
     метод "horizontal" (построчная развёртка, 65536-мерный вектор).
   - Разбиение: 70/30 (полный набор, 600 изображений) и дополнительно
     уменьшенный holdout 50/10 на класс — оба варианта СЛУЧАЙНЫЕ и
     независимые (не paired_correlation_split).
   - Классификатор: `SubspaceConjugacyClassifier(n_subclasses=8)` —
     параметры по умолчанию библиотеки.
   - Скрипт: `main.py` (готовый end-to-end скрипт: датасет -> train/test
     split -> classifier -> отчёт -> артефакты).
   - Метрики: общая accuracy, per-class recall (`evaluation.metrics`),
     confusion matrix.

6. РЕЗУЛЬТАТЫ ЭКСПЕРИМЕНТА (уже получены, источник — README.md, раздел
   «Известные ограничения и особенности метода»)
   - 70/30 split, 600 изображений, n_subclasses=8: общая accuracy = 61%.
     Recall по классам: glioma ~0.82-0.87, pituitary ~0.82-0.87,
     meningioma — систематически хуже, ~0.15.
   - Уменьшенный holdout (50/10 на класс): accuracy = 80%.
   - Оба результата значительно выше случайного угадывания (33%), что
     подтверждает содержательность признакового представления и метода,
     но обнажает системную слабость на классе meningioma — эта находка
     используется как мотивация для Статей 3 и 4 (улучшение отбора
     эталонов и использование структуры смежных срезов).
   - Вывод для диссертации: baseline для сравнения во всех последующих
     статьях — 61% (полный набор, честный сплит).

СТАТЬЯ 2

1. НАЗВАНИЕ
   Предобработка и векторизация чёрно-белых медицинских изображений для
   метода подпространственной сопряжённости

2. АННОТАЦИЯ (черновик, ~140 слов)
   Статья посвящена этапу предварительной обработки одноканальных
   (чёрно-белых) медицинских изображений, предшествующему применению
   метода подпространственной сопряжённости. Рассмотрены операции
   приведения изображений произвольного размера к единому формату,
   подавления фона, центрирования объекта интереса и бинаризации по
   методу Оцу. Отдельно исследуется влияние двух опциональных
   предобработочных фильтров эталонных векторов — фильтрации почти
   линейно зависимых векторов и фильтрации малоинформативных векторов —
   на итоговую точность классификации. Показано, как выбор порога
   бинаризации и параметров фильтрации влияет на устойчивость показателя
   сопряжённости к шуму и артефактам съёмки. Эксперимент проведён на
   наборе МРТ-снимков трёх типов опухолей головного мозга; получены
   количественные оценки прироста/потери точности при включении каждого
   из фильтров по отдельности и совместно.

3. ВВЕДЕНИЕ (план)
   - Специфика медицинских изображений как объекта машинного обучения:
     чувствительность к контрасту, шуму, положению объекта в кадре.
   - Роль предобработки в подпространственных методах: показатель
     сопряжённости чувствителен к масштабу и выравниванию, в отличие от
     инвариантных к сдвигу представлений (например, CNN-эмбеддингов).
   - Обзор существующих подходов к бинаризации и нормализации медицинских
     снимков (пороговые методы, метод Оцу).
   - Постановка задачи: количественно оценить вклад каждого этапа
     предобработки и опционального фильтра в итоговую точность.

4. ТЕОРИЯ (план)
   - Приведение к единому размеру и подавление фона —
     `preprocessing/resize.py`, `preprocessing/normalization.py`,
     `preprocessing/centering.py` (DEFAULT_SIZE = 256x256).
   - Бинаризация по методу Оцу: автоматический подбор порога через
     минимизацию внутриклассовой дисперсии —
     `preprocessing/binarization.py::otsu_threshold/otsu_binarize`
     (находка №4 из theory/code, не часть опубликованной статьи).
   - Векторизация: построчная/постолбцовая развёртка —
     `features/vectorization.py` (методы "horizontal"/"vertical").
   - Фильтр почти линейно зависимых эталонных векторов —
     `algorithms/reference_filter.py::LinearDependencyFilter`.
   - Фильтр малоинформативных векторов (доля «белых» элементов < 50% от
     среднего) — `algorithms/informativeness_filter.py::LowInformativenessFilter`,
     `DEFAULT_BRIGHTNESS_THRESHOLD`, `DEFAULT_MIN_FRACTION_OF_MEAN`.
   - Оба фильтра по умолчанию ВЫКЛЮЧЕНЫ в библиотеке (обратная
     совместимость) — статья обосновывает, когда их включение оправдано.

5. ОПИСАНИЕ ЭКСПЕРИМЕНТА (К ПРОВЕДЕНИЮ)
   - Датасет: тот же, что в Статье 1 (`datasets/*_centered/`).
   - План аблации (4 конфигурации, honest split 80/20 из Статьи 1):
       (a) baseline — без фильтров (как в Статье 1);
       (b) + LinearDependencyFilter;
       (c) + LowInformativenessFilter;
       (d) + оба фильтра одновременно.
   - Дополнительно: сравнение бинаризованных (`otsu_binarize`) и
     небинаризованных векторов на этапе построения эталонных подпространств

     проекции снимка, но вредна для определения типа патологии (см. также
     Статью 6, где это разделение используется явно).
   - Метрики: accuracy, per-class recall, число исключённых фильтрами
     векторов на класс, время построения подпространств (для оценки

   - Скрипт: новый `experiments/experiment_preprocessing_ablation.py`

СТАТЬЯ 3
################################################################################

1. НАЗВАНИЕ
   Стратегии формирования эталонных подпространств при классификации
   медицинских изображений методом сопряжённости

2. АННОТАЦИЯ (черновик, ~150 слов)
   Исследуется влияние стратегии отбора эталонных векторов на точность
   классификации медицинских изображений методом подпространственной
   сопряжённости. Рассмотрены три стратегии формирования подпространства
   класса: случайный отбор, детерминированный отбор по критерию (3)
   (последовательный набор наиболее «непохожих» друг на друга векторов
   через минимум показателя сопряжённости с растущим базисом) и
   альтернативная «оконная» стратегия из MATLAB-прототипа метода. На
   честном независимом разбиении данных показано, как точность
   классификации зависит от объёма обучающей выборки (10-50 эталонов на
   класс) при каждой из трёх стратегий отбора. Обсуждается компромисс
   между «представительностью» (случайный отбор охватывает типичные
   примеры класса) и «разнообразием» (критерий (3) целенаправленно ищет
   крайние, непохожие примеры) обучающей выборки применительно к задаче
   распознавания опухолей головного мозга.

3. ВВЕДЕНИЕ (план)
   - Проблема формирования обучающей выборки в условиях дефицита
     размеченных медицинских данных: почему важно уметь строить
     представительное подпространство класса по малому числу образцов.
   - Обзор идеи чернового варианта статьи-источника
     (theory/code/Вариант_2_1.docx): «Первый этап» (исключение сильно
     коррелированных пар) и «Второй этап» (критерий (3), отбор
     наиболее непохожих векторов).
   - Постановка задачи: сравнить случайный и целенаправленный отбор
     эталонов НА ЧЕСТНОМ разбиении (в отличие от исходного эксперимента
     с paired_correlation_split — см. методологическую поправку в
     Статье 6, которая обязательна к учёту здесь).

4. ТЕОРИЯ (план)
   - Критерий (3): на каждом шаге для всех ещё не отобранных векторов
     класса x вычисляется R(x, Y) относительно уже отобранных векторов Y;
     присоединяется вектор с МИНИМАЛЬНЫМ R (наименее «объясняемый»
     текущим подпространством) — `algorithms/reference_centers.py::ReferenceCenterBuilder`.
   - Начальная пара — глобальный минимум косинусного сходства —
     `algorithms/global_pair.py::GlobalMinCosinePairFinder`.
   - Альтернативная "windowed"-стратегия (theory/code/DATA_100.m,
     Otbor_100.m) — позиционное ограничение пула кандидатов —
     `ReferenceCenterBuilder(strategy="windowed")`.
   - Формальное обоснование инвариантности отбора по критерию (3) к
     порядку входных данных (argmin по значению, а не по позиции) — со
     ссылкой на эмпирическую проверку (см. Статью 6, где этот факт
     измерен: std(accuracy)=0 по 20 случайным перестановкам).

5. ОПИСАНИЕ ЭКСПЕРИМЕНТА
   - Датасет: тот же основной (glioma/meningioma/pituitary, 200/класс).
   - Разбиение: ОБЯЗАТЕЛЬНО `paper_train_test_split` (честный случайный
     80/20), НЕ `paired_correlation_split` — методологический урок,
     полученный в ходе работы над репозиторием (см. Статью 6): на
     paired_correlation_split критерий (3) даёт завышенную и растущую с m
     точность (0.71-0.84), которая почти целиком объясняется утечкой
     между train и test, а не свойствами метода. Все цифры этой статьи
     должны быть получены на честном сплите, усреднённом по нескольким
     (>=20) случайным разбиениям.
   - Объёмы обучающей выборки: m = 10, 20, 30, 40, 50 эталонов на класс.
   - Три конфигурации: random_select, select_by_criterion3 (default),
     select_by_criterion3 (strategy="windowed").
   - Скрипт: адаптация `experiments/experiment_draft_variant2.py`
     (функции `select_by_criterion3`, `run_table8_random_split_sensitivity`
     как образец методологии усреднения по случайным сплитам) —
     новый `experiments/experiment_reference_strategy_comparison.py`.
   - Метрики: mean/std accuracy по >=20 случайным сплитам на каждое m и
     каждую стратегию; per-class recall.

6. РЕЗУЛЬТАТЫ ЭКСПЕРИМЕНТА (частично уже получены — см. пояснение)
   - Уже известно (Статья 6 / artifacts/experiment_draft_variant2_report.json,
     table8_random_split_sensitivity): критерий (3) на честном сплите даёт
     accuracy ~0.32-0.34 ПРАКТИЧЕСКИ БЕЗ РОСТА от m=10 до m=50 — то есть
     сам по себе, без ансамбля подклассов SubspaceConjugacyClassifier,
     метод «критерий (3) + одно подпространство на класс» на честной
     оценке работает на уровне, близком к случайному угадыванию (33%).
   - К ПРОВЕДЕНИЮ в этой статье: (а) сравнение с random_select на тех же
     честных сплитах (есть ли вообще преимущество критерия (3) над
     случайным отбором при равном m, если оба оцениваются честно?);
     (б) сравнение default vs windowed стратегий.
   - Ожидаемый вывод для диссертации: при однопространственной схеме
     (без подклассов) выбор стратегии отбора эталонов, вероятно, вторичен
     по сравнению с самим фактом использования МНОЖЕСТВЕННЫХ подклассов
     на класс (как в каноническом SubspaceConjugacyClassifier, Статья 1) —
     эта гипотеза формулируется здесь и проверяется количественно.

самостоятельна и не ссылается на какой-либо классический
("подпространственный") результат.

1. НАЗВАНИЕ
   Анализ последовательной структуры смежных срезов медицинских
   изображений методом свёрточных нейронных сетей

2. АННОТАЦИЯ (черновик, ~160 слов)
   Медицинские изображения (МРТ, КТ) часто представляют собой не отдельные
   независимые снимки, а последовательность срезов одного и того же
   объекта исследования, соседние элементы которой пространственно и
   визуально коррелированы. В статье рассматривается задача попиксельной
   сегментации опухоли головного мозга на МРТ-срезах свёрточной
   нейронной сетью (U-Net) и исследуется, помогает ли учёт нескольких
   физически смежных по оси срезов (в виде дополнительных входных
   каналов изображения, "2.5D"-представление) точнее выделять границы
   опухоли по сравнению с сегментацией одного изолированного срeза.
   Качество сегментации оценивается коэффициентом Дайса (Dice) — в
   отличие от пиксельной accuracy, эта метрика не завышена сильным
   классовым перекосом, типичным для задач сегментации (опухоль обычно
   занимает лишь единицы процентов площади срeза). Проведён контролируемый
   эксперимент на реальных данных (BraTS2020, FLAIR), сравнивающий модель
   без контекста соседних срезов, модель со стеком физически смежных
   срезов и ту же модель на искусственно перемешанных "соседях" — как
   проверка того, что обнаруженный эффект, если он есть, объясняется
   именно физической смежностью срезов, а не просто большим объёмом
   входной информации.

3. ВВЕДЕНИЕ (план)
   - Медицинская мотивация: снимки одного пациента (например,
     последовательные срезы МРТ-исследования) визуально и статистически
     ближе друг к другу, чем снимки разных пациентов — это структурная
     информация, которую сегментация одного изолированного срeза не
     использует, хотя соседние срезы могут содержать подсказку о форме и
     границах той же опухоли.
   - Связь с темой диссертации: это единственный из 6 экспериментов,
     где «последовательность» — не метафора (порядок train/test или
     этапов пайплайна), а буквальный физический порядок срезов.
   - Выбор метрики: почему пиксельная accuracy систематически завышена
     при сегментации малых объектов (опухоль — единицы процентов площади
     срeза; модель, всегда предсказывающая "фон", уже получает accuracy
     >95% без какого-либо реального качества сегментации) и почему Dice —
     корректная основная метрика статьи.
   - Постановка задачи: научится ли свёрточная сеть использовать
     физическую смежность срезов для более точной сегментации, и можно ли
     это измерить формальной проверкой гипотез (H1/H2) на честном
     патиентском сплите.

4. ТЕОРИЯ (план)
   - Задача: бинарная попиксельная сегментация (опухоль/фон) по срезу
     FLAIR — упрощённый вариант 4-классовой сегментации подобластей
     опухоли (некроз/отёк/усиливающаяся часть) из эталонных ноутбуков
     `state4_scripts/3d-mri-brain-tumor-segmentation-u-net*.ipynb`; маска
     "опухоль" — объединение всех ненулевых меток `_seg.nii`
     ("whole tumor" в терминологии BraTS).
   - Архитектура: компактный U-Net (энкодер 32->64->128->256 с
     max-pooling, decoder с транспонированными свёртками и
     skip-connections, как в оригинальной работе Ronneberger et al.) —
     семейный паттерн эталонных ноутбуков, но меньше (без 512-канального
     уровня) для практичности на CPU, перенесён с Keras/TensorFlow на
     PyTorch (опциональная зависимость проекта) —
     `experiments/experiment_article4_unet_segmentation.py::SmallUNet`.
   - 2.5D-представление последовательности: N соседних по оси Z срезов
     подаются как ОТДЕЛЬНЫЕ ВХОДНЫЕ КАНАЛЫ одного тензора (N, H, W);
     первый свёрточный слой энкодера сам обучается весам для каждого
     канала-соседа — не фиксированная формула комбинирования, а параметр,
     оптимизируемый по данным, в отличие от скользящего усреднения.
   - Функция потерь: комбинация binary cross-entropy + soft Dice loss —
     стандартный приём для сегментации с сильным классовым перекосом
     (чистый BCE слабо штрафует пропуск малого объекта).
   - Формальное условие корректности: 2.5D-представление имеет смысл
     только для физически смежных срезов одного пациента — проверяется
     H1/H2-аппаратом (см. п. 5-6).

5. ОПИСАНИЕ ЭКСПЕРИМЕНТА (проведено)
   - Датасет: `datasets/brats_flair_slices/` (BraTS2020, FLAIR, 160
     пациентов, срезы с сохранённым физическим порядком по оси Z) +
     бинарные маски опухоли, подготовленные
     `experiments/prepare_brats_segmentation_masks.py` (воспроизводит тот
     же геометрический путь resize/подавление фона/центрирование, что и
     уже сохранённые FLAIR-PNG, чтобы маска была пиксельно выровнена с
     изображением — маски не создавались на этапе первой подготовки
     данных, т.к. тогда задачей была классификация, не сегментация).
   - Разбиение: случайный сплит по patient_id (RANDOM_SEED=42, 80/20,
     128 train / 32 test пациентов).
   - Три конфигурации сравнения (аналог H1/H2):
       1. `no_context_k1` — U-Net на одном срезе, 1 входной канал.
       2. `meaningful_neighbors` — та же архитектура, вход — стек из
          N=5 физически смежных срезов как входных каналов (2.5D).
       3. `shuffled_neighbors` — ТА ЖЕ обученная модель конфигурации 2,
          но "соседи" на входе заменены случайными срезами из тестового
          пула (центральный срез и его маска — те же) — H2-контроль: если
          Dice падает к уровню конфигурации 1 (или ниже), модель
          действительно использует физическую смежность, а не просто
          получает больше "сырых" пикселей на вход.
   - Обучающая выборка: до 1500 срезов на подвыборку (сбалансированную по
     has_tumor), 128x128, 8 эпох, Adam(lr=1e-3), loss = BCE + Dice.
   - Скрипт: `experiments/experiment_article4_unet_segmentation.py`.
   - Метрики: Dice (основная), пиксельная accuracy (приведена только для
     прозрачности и для демонстрации её неинформативности — см. п. 3) —
     для всех 3 конфигураций на одном и том же честном held-out наборе
     пациентов.

6. РЕЗУЛЬТАТЫ ЭКСПЕРИМЕНТА (получены, 2026-10-08)
   Источник: `artifacts/experiment_article4_unet_report.json` /
   `experiment_article4_unet_results.md` (n_test=4177 срезов 32 held-out
   пациентов; обучение — 2000 срезов, 96x96, 6 эпох).

   | Конфигурация | mean Dice | median Dice | pixel accuracy |
   |---|---|---|---|
   | no_context_k1 (без контекста) | 0.5055 | 0.500 | 0.9871 |
   | meaningful_neighbors (K=5, физические соседи) | 0.6930 | 0.920 | 0.9923 |
   | shuffled_neighbors (K=5, случайные "соседи") | 0.4861 | 0.167 | 0.9867 |

   ГЛАВНЫЙ РЕЗУЛЬТАТ — H1 ПОДТВЕРЖДЕНА, и значительно: mean Dice
   meaningful_neighbors (0.693) > no_context_k1 (0.506) -> **True**, рост
   +18.8 п.п. Dice. Эффект гораздо заметнее по медиане (0.92 против 0.50,
   т.е. для ТИПИЧНОГО срeза с опухолью сеть со стеком соседей выдаёт почти
   точное совпадение с разметкой, а без контекста — лишь наполовину) —
   контекст соседних срезов даёт сети реальную информацию о форме и
   границах опухоли, которой одного изолированного срeза не хватает. Это
   первое прямое подтверждение центрального тезиса статьи («последо-
   вательная структура смежных срезов повышает качество») за всю историю
   Статьи 4 — ни классический метод (сглаживание признаков), ни
   нейросетевая классификация has_tumor/no_tumor такого подтверждения не
   дали (см. [[project-article4-cnn-pivot]]). Вероятное объяснение разницы:
   бинарная метка "есть ли опухоль на срeзе" почти полностью считывается с
   одного срeза, а вот ТОЧНАЯ ГРАНИЦА опухоли (попиксельная задача) —
   действительно дополняется информацией о форме с соседних срезов, где
   опухоль занимает частично иную, но перекрывающуюся область.

   H2 (случайные "соседи" не лучше физически смежных: shuffled_neighbors
   <= meaningful_neighbors): 0.486 <= 0.693 -> **подтверждена**, с очень
   большим разрывом (20.7 п.п. по mean Dice, с 0.92 до 0.167 по медиане —
   обвал почти в 6 раз). Показательно, что shuffled_neighbors даже НИЖЕ
   no_context_k1 (0.486 против 0.506) — модель, обученная ожидать
   физически смежные каналы, активно "сбивается" случайными каналами, а
   не просто игнорирует их: лишняя неинформативная "соседская" информация
   не нейтральна, а вредна. Это сильное прямое доказательство того, что
   сеть действительно научилась использовать физическую смежность, а не
   просто получила больше сырых пикселей на вход.

   Иллюстрация методологического урока про метрики (п.3): пиксельная
   accuracy почти не меняется между конфигурациями (0.987 / 0.992 / 0.987
   — разброс всего ~0.6 п.п.), тогда как Dice показывает контраст в
   десятки процентных пунктов — нагляднейшее на собственных данных статьи
   подтверждение того, почему accuracy — неподходящая метрика для
   сегментации при сильном классовом перекосе, а Dice — обязательная
   основная метрика.

   Вывод для диссертации: смена задачи (с бинарной классификации срeза на
   попиксельную сегментацию опухоли) и переход на обучаемую 2.5D-архитектуру
   ОДНОВРЕМЕННО решают обе проблемы предыдущих версий статьи — дают
   содержательную абсолютную метрику качества (Dice ~0.69, разумный
   результат для компактного CPU-дружественного U-Net без аугментаций и
   полноценного датасета) И статистически убедительное подтверждение
   центральной гипотезы о пользе последовательной структуры смежных
   срезов, причём с рабочим, проверенным H2-контролем.

1. НАЗВАНИЕ
   Применимость метода подпространственной сопряжённости для покадровой
   классификации медицинских видеопотоков в реальном времени

2. АННОТАЦИЯ (черновик, ~170 слов)
   Исследуется применимость метода подпространственной сопряжённости к
   классификации не отдельных статичных снимков, а видеопоследовательностей
   и потокового видео медицинской визуализации (эндоскопия, УЗИ,
   флюороскопия) — модальностей, для которых кадр по своей природе является
   элементом упорядоченной во времени последовательности, а не независимым
   изображением. Показано, что классификация уже обученной моделью
   (`SubspaceConjugacyClassifier.predict`) на один кадр 256x256 занимает
   около 7.8 мс, что соответствует теоретической пропускной способности
   порядка 128 кадров в секунду на процессоре общего назначения без
   GPU-ускорения — с запасом достаточно для потоков 25-60 fps, типичных
   для медицинского видео. При этом само обучение модели (формирование
   эталонных подпространств на исходной выборке) — существенно более
   затратная по времени офлайн-процедура, не пригодная для выполнения «на
   лету» в её текущей реализации. Обсуждаются условия, при которых метод
   применим к видео (кадр как независимая точка признакового пространства,
   использование временной смежности кадров по аналогии со смежными
   срезами МРТ), и ограничения (отсутствие явной модели движения,
   отсутствие в библиотеке инкрементального дообучения подпространств).

3. ВВЕДЕНИЕ (план)
   - Мотивация: часть медицинских модальностей визуализации (эндоскопия,
     колоноскопия, УЗИ, интраоперационное видео) — по своей природе
     видеопоток, а не набор отдельных снимков; классификация в реальном
     времени во время процедуры имеет самостоятельную клиническую ценность
     (например, обнаружение патологии по ходу эндоскопического
     исследования).
   - Связь с темой диссертации: видео — предельный случай
     «последовательности медицинских изображений» из Статьи 4, где
     временной порядок кадров не суррогатный, а физически точный и
     плотный (десятки кадров в секунду), что снимает ограничение Статьи 4
     (отсутствие метаданных порядка срезов у используемого MRI-датасета).
   - Постановка задачи: разделить вопрос на два независимых — (1)
     вычислительная применимость (успевает ли метод классифицировать кадр
     до прихода следующего) и (2) применимость по точности (даёт ли
     покадровая классификация с учётом временной смежности приемлемое
     качество на реальном видео).

4. ТЕОРИЯ (план)
   - Разделение вычислительной стоимости на этап обучения (`fit`) и этап
     предсказания (`predict`): построение эталонных подпространств —
     батчевая процедура над ВСЕЙ обучающей выборкой класса (фазы A и B,
     `algorithms/global_pair.py`, `algorithms/reference_centers.py`,
     `algorithms/subclass_growth.py`) выполняется один раз офлайн;
     классификация нового вектора — `conjugate_criterion(x, Y_s)` для
     каждого из C x n_subclasses уже готовых подпространств, стоимость
     O(N x k) на подпространство (N — размерность вектора, k — размер
     базиса подкласса, обычно 2) — не требует пересчёта матрицы Грама
     обучающей выборки и линейна по числу кадров.
   - Требование к разрешению кадра: вектор признаков строится построчной
     развёрткой кадра (`features/vectorization.py`), поэтому сырое видео
     (например, 1920x1080) необходимо предварительно уменьшать до
     фиксированного малого размера (256x256, как и для МРТ-снимков,
     `preprocessing/resize.py::DEFAULT_SIZE`) — от этого размера линейно
     зависит стоимость и обучения, и предсказания.
   - Видео как последовательность кадров: применимость
     `features/smoothing.py::smooth_adjacent_vectors` к окну соседних по
     времени кадров — тот же механизм, что и в Статье 4, но здесь порядок
     кадров всегда физически точен (в отличие от МРТ-датасета без
     метаданных серии).
   - Ограничения метода применительно к видео (сформулировать как
     теоретические, проверяемые экспериментально ниже):
       (а) метод не содержит явной модели движения (в отличие от
           оптического потока/3D-свёрток в video-CNN) — пригоден для
           задач, где решающий признак статичен внутри кадра (например,
           наличие/тип находки), но не для задач, которым принципиально
           нужна динамика (жест, действие);
       (б) в тексте статьи-источника упоминается, что «в процессе
           распознавания обучающее подпространство может быть расширено
           за счёт введения новых векторов, принадлежность которых к
           данному классу не вызывает сомнений»
           (`algorithms/reference_centers.py`, docstring, п. 25 теории) —
           но инкрементальное дообучение (`partial_fit`/потоковое
           обновление подпространства) в библиотеке НЕ реализовано; любое
           обновление модели по ходу потока сегодня означает полный
           повторный `fit()` на всей накопленной выборке.

5. ОПИСАНИЕ ЭКСПЕРИМЕНТА
   Часть А — вычислительная применимость (уже проведено, воспроизводимо
   без нового датасета, на существующих datasets/*_centered/):
   - Обучение `SubspaceConjugacyClassifier(n_subclasses=8, freeze_basis_at=2)`
     на 600 изображениях (200/класс, как в Статье 1) — измерение времени
     `fit()`.
   - Замер задержки `predict()` на одном кадре (имитация поступления
     одного кадра видеопотока), 200 повторов после разогрева, и на батче
     из 64 кадров (имитация буферизованной обработки).
   - Скрипт: разовый бенчмарк (может быть оформлен как
     `experiments/experiment_video_latency_benchmark.py` для
     воспроизводимости в статье).

   Часть Б — применимость по точности на реальном видео (К ПРОВЕДЕНИЮ):
   - Ограничение датасета: в репозитории нет чёрно-белого медицинского
     видеодатасета — необходимо получить внешний источник, например,
     общедоступные наборы кадров эндоскопии/колоноскопии или
     ультразвукового видео (грayscale по своей природе). План на случай
     недоступности размеченного медицинского видео к моменту написания
     статьи: использовать любой общедоступный чёрно-белый (или
     переведённый в grayscale) видеоряд с покадровой разметкой класса как
     методологический суррогат, явно отметив это ограничение — по
     аналогии с суррогатным порядком в Статье 4.
   - Три конфигурации сравнения (методология идентична Статье 4):
       1. Покадровая классификация без учёта временной смежности
          (baseline — каждый кадр независимо).
       2. Покадровая классификация со сглаживанием признаков по окну
          соседних кадров (`smooth_adjacent_vectors`).
       3. То же сглаживание на кадрах со случайно перемешанным порядком
          (контроль, как в Статье 4).
   - Метрики: accuracy/recall по кадрам, задержка end-to-end на кадр
     (препроцессинг + векторизация + предсказание) в сравнении с бюджетом
     кадра (33 мс при 30 fps, 16.7 мс при 60 fps).

6. РЕЗУЛЬТАТЫ ЭКСПЕРИМЕНТА
   Часть А (уже получены):
   - `fit()` на 600 изображениях (n_subclasses=8): 858 секунд (~14.3 мин) —
     разовая офлайн-процедура, неприменима для обучения «на лету» в
     процессе показа видео в её текущем виде.
   - `predict()` на одном кадре: 7.818 мс/кадр (200 повторов) — то есть
     теоретический потолок пропускной способности порядка 128 кадров в
     секунду на одном CPU-ядре, без какой-либо GPU-акселерации. Для
     батча из 64 кадров — 6.006 мс/кадр в среднем (амортизация накладных
     расходов).
   - Вывод: классификация УЖЕ ОБУЧЕННОЙ моделью с запасом укладывается в
     бюджет кадра для типичных частот медицинского видео (25-60 fps) — по
     чистой вычислительной стоимости `predict()` метод пригоден для
     потоковой обработки в реальном времени. Узкое место — не
     классификация, а (пере)обучение модели, которое остаётся офлайн-
     задачей при текущей реализации библиотеки.
   Часть Б (К ПРОВЕДЕНИЮ):
   - Ожидаемый формат — как в Статье 4: таблица 3 строки x
     {accuracy, per-class recall, задержка end-to-end на кадр}.
   - Открытый вопрос для диссертации, требующий отдельной проверки:
     сохраняется ли системная слабость на классе meningioma (Статьи 1, 3)
     при переносе метода на другую модальность и другой домен видео, или
     это специфика конкретного датасета МРТ-снимков.
   - Рекомендация по дальнейшей работе (естественное продолжение п. 4(б)
     теории): реализация инкрементального обновления подпространств
     (добавление новых уверенно классифицированных кадров к
     `ReferenceCenterBuilder`/`ConjugacyClusterGrowth` без полного
     повторного `fit()`) как отдельная техническая задача, выходящая за
     рамки текущей библиотеки, но напрямую вытекающая из результатов этой
     статьи.

1. НАЗВАНИЕ
   Методология корректной оценки точности и двухэтапный последовательный
   пайплайн классификации медицинских изображений

2. АННОТАЦИЯ (черновик, ~170 слов)
   Статья решает две связанные задачи. Во-первых, эмпирически
   демонстрируется методологический артефакт оценки точности в задачах
   классификации медицинских изображений: при использовании схемы
   разбиения данных, намеренно подбирающей тестовую выборку похожей на
   обучающую (что обосновывается через попарное разнесение сильно
   коррелированных изображений), точность метода сопряжённости составляет
   0.71-0.84 и растёт с объёмом обучающей выборки, тогда как на честном
   независимом случайном разбиении она падает до 0.32-0.34 — уровня,
   близкого к случайному угадыванию — и не растёт с объёмом обучающей
   выборки вовсе. Отдельно показано, что сам алгоритм отбора эталонных
   векторов детерминирован по содержанию данных и не зависит от порядка
   их поступления (нулевая дисперсия точности по 20 случайным
   перестановкам при фиксированном разбиении на train/test). Во-вторых,
   на основе усвоенного методологического урока предлагается и
   оценивается двухэтапный последовательный пайплайн классификации
   (определение проекции снимка, затем определение типа патологии
   отдельным классификатором для каждой проекции) как практическая
   архитектура, корректно оцениваемая по честной методологии.

3. ВВЕДЕНИЕ (план)
   - Проблема воспроизводимости и корректности оценки в работах по
     машинному обучению для медицинских изображений: как схема разбиения
     данных на train/test может искусственно завышать заявляемую точность.
   - Обзор понятия «утечка данных» (data leakage) применительно к
     коррелированным медицинским изображениям (например, несколько
     срезов одного пациента, случайно разнесённые между train и test).
   - Идея двухэтапной последовательной классификации из статьи-источника
     (Korshikov & Fursov): «...it is capable of performing sequential
     classification. The first step involves the identification of the
     essential feature, and the second step involves the classification
     of objects for which this feature is matched» — определение проекции
     снимка (axial/sagittal/coronal), затем определение типа патологии
     отдельным классификатором для каждой проекции.
   - Тезис статьи: методология оценки и архитектура пайплайна должны
     разрабатываться совместно — некорректная оценка маскирует реальную
     работоспособность даже корректно спроектированного пайплайна.

4. ТЕОРИЯ (план)
   - Формальное сравнение `paired_correlation_split` («Первый этап»
     чернового варианта статьи-источника — попарное разнесение сильно
     коррелированных изображений между train/test) и
     `paper_train_test_split` (честный стратифицированный случайный
     сплит, методология опубликованной статьи) —
     `evaluation/paper_methodology.py`.
   - Формальное обоснование инвариантности argmin/argmax-отбора к
     порядку данных: показатель сопряжённости и косинусное сходство
     вычисляются по СОДЕРЖАНИЮ вектора, а не по его позиции в массиве;
     единственный сценарий нарушения — точное числовое совпадение
     показателей у разных изображений.
   - Архитектура двухэтапного пайплайна —
     `models/sequential_classifier.py::SequentialClassifier` (находка №4):
     классификатор этапа 1 (любой sklearn-совместимый) + словарь
     классификаторов этапа 2 (по одному на каждое значение, предсказанное
     этапом 1). Согласно статье-источнику, этап 1 использует
     Otsu-бинаризованные векторы, этап 2 — небинаризованные.

5. ОПИСАНИЕ ЭКСПЕРИМЕНТА
   Часть А — методологический артефакт (уже проведено):
   - Датасет и метод — как в Статье 3 (критерий (3), m=10..50).
   - Часть А.1 (уже проведено): 20 случайных перестановок порядка
     векторов ВНУТРИ одного и того же `paired_correlation_split` для
     каждого m — измерение std(accuracy) и совпадения фактически
     отобранных эталонов.
   - Часть А.2 (уже проведено): 20 НЕЗАВИСИМЫХ случайных сплитов
     `paper_train_test_split` (80/20) для каждого m — измерение
     mean/std/min/max accuracy в сравнении с одноточечным результатом на
     `paired_correlation_split`.
   - Скрипт: `experiments/experiment_draft_variant2.py::run_table8_random_split_sensitivity`,
     артефакт — `artifacts/experiment_draft_variant2_report.json` (ключ
     `table8_random_split_sensitivity`).

   Часть Б — двухэтапный пайплайн (К ПРОВЕДЕНИЮ):
   - Ограничение датасета (аналогично Статье 4): используемый Kaggle-набор
     не содержит меток проекции снимка (axial/sagittal/coronal). План:
       (а) получить датасет с разметкой по проекции, либо
       (б) для методологической демонстрации пайплайна использовать

           признаков снимка, извлекаемых из Otsu-бинаризации — форма/
           ориентация контура — как суррогат «проекции»), явно отметив
           это как упрощение до появления данных с реальной разметкой.
   - Этап 1: классификатор на Otsu-бинаризованных векторах
     (`preprocessing.binarization.otsu_binarize`).
   - Этап 2: для каждого предсказанного этапом 1 значения — отдельный
     `SubspaceConjugacyClassifier` на небинаризованных векторах,
     предсказывающий тип патологии.
   - Оценка ОБЯЗАТЕЛЬНО через `paper_train_test_split`, усреднение по
     >=20 случайным сплитам (методологический урок части А применяется
     здесь на практике).
   - Скрипт: новый `experiments/experiment_sequential_pipeline.py`,
     использующий `SequentialClassifier`.

6. РЕЗУЛЬТАТЫ ЭКСПЕРИМЕНТА
   Часть А (уже получены):
   - Порядок данных внутри фиксированного сплита: std(accuracy) = 0.000000
     по 20 перестановкам для ВСЕХ m∈{10,20,30,40,50}; набор фактически
     отобранных эталонов идентичен во всех перестановках — метод
     детерминирован по данным, не по порядку их поступления.
   - Случайный состав train/test: accuracy падает с 0.71-0.84
     (paired_correlation_split, растёт с m) до 0.32-0.34 (честный сплит,
     не растёт с m) — разрыв от 0.37 до 0.50 в абсолютных пунктах точности
     в зависимости от m. Вывод: рост точности с объёмом обучающей выборки
     в исходной методологии статьи-источника — преимущественно артефакт
     утечки между train и test, а не свойство метода.
   Часть Б (К ПРОВЕДЕНИЮ):
   - Ожидаемый формат: accuracy этапа 1 (определение проекции/прокси-
     признака) отдельно; итоговая accuracy этапа 2 (тип патологии) в
     сравнении с одноэтапной схемой (Статья 1, 61% на честном сплите) —
     проверка гипотезы статьи-источника о том, что предварительное
     разделение на однородные подгруппы (по проекции) облегчает
     последующую классификацию патологии внутри каждой подгруппы.
   - Итоговый раздел диссертации: сформулировать практические
     рекомендации по корректной оценке моделей классификации медицинских
     изображений (обязательность независимого случайного разбиения,
     недопустимость коррелированных пар между train/test, необходимость
     усреднения по нескольким сплитам вместо отчёта по одному) — прямое
     следствие Части А, применимое не только к методу сопряжённости, но
     и к любому классификатору медицинских изображений.
