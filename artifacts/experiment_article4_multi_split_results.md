# Статья 4 — валидация H1/H2 по нескольким независимым разбиениям train/test

5 независимых случайных патиентских разбиений (split_seed = [42, 101, 202, 303, 404]), базовый U-Net (с BatchNorm), 6 эпох, K=5. Устройство: cuda (NVIDIA GeForce GTX 1650).

По требованию медицинского рецензента (medical_article_requirements.txt, п.5): один прогон на одном разбиении недостаточен для вывода — ниже тот же эксперимент на нескольких независимых разбиениях.

| split_seed | no_context (с опухолью) | meaningful | shuffled | H1 | H2 |
|---|---|---|---|---|---|
| 42 | 0.6756 | 0.6248 | 0.0414 | False | True |
| 101 | 0.5472 | 0.6678 | 0.0657 | True | True |
| 202 | 0.5579 | 0.6330 | 0.0522 | True | True |
| 303 | 0.6766 | 0.6909 | 0.2001 | True | True |
| 404 | 0.4799 | 0.5418 | 0.0758 | True | True |

| Метрика | mean | std | min | max |
|---|---|---|---|---|
| no_context_dice_tumor | 0.5875 | 0.0772 | 0.4799 | 0.6766 |

**H1 подтверждена в 4/5 разбиениях.** **H2 подтверждена в 5/5 разбиениях.**

Ограничение: валидация охватывает только базовый U-Net (headline-модель статьи) на бюджете 6 эпох, не все 8 сравниваемых архитектур и не полную сетку в 15 эпох — ради контроля суммарного времени эксперимента. Распространение на все архитектуры — следующий шаг при необходимости.
